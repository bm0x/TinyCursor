Security & Transparency

Privacy Policy

Last Updated: September 2026

TinyCursor is dedicated to user privacy and open-source transparency. When using TinyCursor, you can be completely confident that:

  • No Personal Data Collection: TinyCursor does not collect, record, transmit, or monetize any personal information, keystrokes, clipboard data, or browsing activity.
  • Local-Only Processing: Luminance sampling used for dynamic theme switching is performed strictly in real-time volatile memory (GPU/RAM) around the mouse pointer and is never saved to disk.
  • Zero Network Calls: TinyCursor does not contain any analytics SDKs, trackers, telemetry beacons, or external network connections. It functions completely offline.
  • Auditable Code: The entire codebase is open source under the MIT License and publicly verifiable on GitHub.
